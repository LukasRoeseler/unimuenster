A note before you start

Quantitative metrics are not a proxy for research quality. Publication and citation counts measure volume and attention — not significance, rigour, or societal value. Read every figure here as context, never as a verdict on a person, group, or field.

This dashboard is a free and open-source alternative to commercial tools such as SciVal, built so that bibliometric transparency need not depend on a paid subscription.

Methods

Where does the data come from?

Read this before interpreting any figure on this page.

The data pipeline

Every figure is derived from OpenAlex, an open, freely licensed (CC0) catalogue of the world's scholarly works, authors, institutions and venues. A scheduled GitHub Action queries the OpenAlex REST API once per week and commits the responses as static JSON into this repository; the page then renders those snapshots entirely in your browser. There is no backend, no database, and no tracking — the whole tool is one static HTML file plus a folder of cached API responses.

Works are attributed to Münster via its OpenAlex institution ID (I22465464). Disciplines, topics and the four Impact Areas are derived from OpenAlex's automated topic classification, not from any faculty roster.

Limitations

  • Metrics ≠ quality. Counts capture volume and attention, never significance or rigour.
  • Coverage gaps. OpenAlex indexes works with a discoverable record; books, reports, non-English and pre-2000 output are under-represented.
  • Classification is algorithmic. Topic, field and SDG tags are machine-assigned and occasionally wrong.
  • Author disambiguation is automated and can merge or split people.

How is this different from Scopus or Web of Science?

Scopus (Elsevier) and Web of Science (Clarivate) are curated, selective databases behind paid subscriptions: an editorial board decides which journals are indexed, which tends to favour established, English-language, journal-based fields. OpenAlex is open and inclusive — it ingests Crossref, PubMed, the former Microsoft Academic Graph, repositories and more under a CC0 licence, so it is broader (more preprints, datasets, books, Global-South and non-English output) but less hand-curated. Consequently absolute counts here will differ from a SciVal/InCites report built on Scopus/WoS; treat the numbers as one open lens, not as the single ground truth. Commercial tools also offer field-normalised indicators (e.g. FWCI) that OpenAlex does not provide out of the box.

What this dashboard does not use

It does not use the University's research-information system (CRIS). Münster's internal CRIS holds authoritative, locally curated records — including complete project, funding and personnel data — but it is internal and not openly licensed. This dashboard deliberately relies only on the public OpenAlex data so that anyone can reproduce it.

Funding & cost data are limited. OpenAlex records some funder acknowledgements but no programme-level detail (DFG SFBs, Exzellenzstrategie clusters) and no euro amounts; those live in the CRIS and in DFG GEPRIS. Likewise, money spent on APCs and journal subscriptions is not in OpenAlex — APC spending is tracked by the OpenAPC initiative, and subscription costs sit in library budgets. See the answers in the project notes for detail.

Understanding OA types: Gold — published in a fully open-access journal. Diamond — fully open access with no author-facing fee. Green — freely available via a repository deposit. Hybrid — open under an APC in a subscription journal. Bronze — free to read on the publisher site without a stated licence. Closed — accessible only via subscription or paywall.

How costs are estimated. A recorded paid APC (via OpenAPC) is trusted whenever present. Preprints and diamond OA works are treated as free. Gold/hybrid works without a paid record fall back to the journal's list price (an estimate, not necessarily what was actually paid). Green/bronze/closed/unknown works carry no direct APC by this route, though they may still cost the library via a subscription, which OpenAlex does not expose per work. How matches are found. The Retraction Watch Database's Institution and Country fields are free text, not linked to OpenAlex or any other institution registry, so records here are matched by searching for a "Münster" name variant in the institution field (guarding against the unrelated Irish province of the same name). This can both miss records where Münster isn't named in that field and, rarely, include a false positive.
